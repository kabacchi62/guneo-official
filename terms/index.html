制定日：2026年11月16日

本利用規約（以下「本規約」）は、#ぐねお運営者（以下「運営者」）が提供するゲーム『#ぐねお / #GUNEO』（以下「本サービス」）の利用条件を定めるものです。

本サービスを利用する方（以下「ユーザー」）は、本規約に同意のうえ、本サービスをご利用ください。

第1条（適用範囲）

本規約は、運営者が提供する『#ぐねお』のAndroidアプリ版および公式サイト上のブラウザ版に適用されます。

第2条（サービス内容）

  1. 本サービスは、キャラクターを操作して障害物を避け、スコアを競うゲームです。
  2. 本サービスには、ゲーム内コイン、ガチャ、キャラクタースキン、広告視聴による報酬などの機能があります。
  3. ランキング機能など、一部の機能は開発中または提供準備中の場合があります。
  4. 運営者は、必要に応じて本サービスの内容を変更、追加または終了することがあります。

第3条（利用料金）

  1. 本サービスは基本無料で利用できます。
  2. 本サービスには広告が表示される場合があります。
  3. 現時点では、ゲーム内コインやアイテムを現金で購入する機能は提供していません。
  4. 通信に必要な費用はユーザーの負担となります。

第4条（ゲーム内コイン・アイテム）

  1. ゲーム内コインは、ゲームプレイや広告視聴など、運営者が定める方法で獲得できます。
  2. ゲーム内コインは本サービス内でのみ利用でき、現金への換金、払い戻し、第三者への譲渡はできません。
  3. ガチャで獲得するアイテムは、運営者が定める抽選方法によって決定されます。
  4. ゲーム内コインやアイテムについて、現実世界での金銭的価値は保証されません。
  5. アプリの削除、端末変更、データ破損などによってゲームデータが失われる場合があります。

第5条（広告）

  1. 本サービスでは、第三者の広告配信サービスを利用する場合があります。
  2. 一部のゲーム内報酬は、広告の視聴完了を条件として付与されます。
  3. 通信障害、広告の配信状況、技術的な問題などにより、広告の表示や報酬の付与が正常に行われない場合があります。

第6条（禁止事項）

ユーザーは、以下の行為を行ってはなりません。

  1. チート、不正なプログラム、データ改ざんなどによってゲームを不正に操作する行為
  2. 本サービスの運営を妨害する行為
  3. 他のユーザーに対する嫌がらせ、誹謗中傷などの行為
  4. 他者の権利を侵害する行為
  5. 本サービスのプログラムやデータを不正に複製、改変、配布する行為
  6. 法令または公序良俗に反する行為
  7. その他、運営者が不適切と判断する行為

第7条（ランキング・ユーザー名）

  1. ランキング機能が提供される場合、運営者が定めるルールに従って利用するものとします。
